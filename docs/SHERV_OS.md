## Controls
1. Read the repository and linked Linear issue before editing.
2. Preserve the narrow utility wedge and avoid unrelated expansion.
3. Run native lint, typecheck, tests, build, and browser interaction checks.
4. Preserve recording routes, width-guide behavior, and launch assets.
5. Do not capture sensitive inputs or recording-route activity in analytics.
6. Production deploys, publishing, credentials, billing, and destructive changes require human approval.
7. Releases document validation, remaining risks, rollback, screenshots, and recordings.
8. Missing capabilities fail closed and are reported explicitly.

Activation is meaningful demo interaction, guide use, or implementation copy.
